Four Pillars of the Revamp

We are not just redesigning pages; we are engineering tailored application interfaces for every stakeholder in the IITG ecosystem.

ONGOING COURSE
Student / Faculty

1. The Learning Management System

Moving beyond flat-white interfaces, we introduce an engineered, dark-mode learning environment. Deep obsidian backgrounds reduce eye strain, while sticky global navigation ensures users never get lost.

  • Distraction-free content consumption.
  • Role-based views (Student progress vs. Faculty grading).
  • Neon-cyan active states for clear computational feedback.
Administration

2. Headless Content Management

Empowering IIT Guwahati staff to manage the platform without developer intervention. A data-dense, scannable backend UI handles complex course structures, news, and faculty directories.

  • Decoupled architecture for unbreakable frontends.
  • Visual publishing states (Draft, Review, Live).
  • Standardized UI blocks for rapid page generation.

3. Active Enquiry Kanban

Standard institutional sites dump form submissions into a generic inbox. We propose an active, workable Kanban board to manage prospective enrollments dynamically.

  • Visual columns mapping the applicant journey.
  • Omnichannel hooks (WhatsApp & Mail integration).
  • Asynchronous Laravel queue processing (Zero lag).
Onboarding

4. Frictionless Registration

Eliminating the drop-off rates associated with long, monolithic government forms. Our segmented UI breaks enrollment into manageable, distraction-free steps.

  • Time-To-Live (TTL) Session retention.
  • Drop off and return exactly where you left off.
  • Clear, illuminating visual feedback upon validation.

Optimized Architecture

Leveraging modern web technologies to ensure scalability, security, and lightning-fast load times.

Astro.js

The frontend engine. Generates zero-JavaScript static HTML for the Academy site, ensuring perfect SEO and instant page loads.

Directus CMS

The headless content nervous system. Provides a beautiful GUI for staff to manage database schemas and API content visually.

Laravel & Postgres

The application backend. Handles complex TTL registrations, strict relational academic records, and secure Role-Based Access Controls.
